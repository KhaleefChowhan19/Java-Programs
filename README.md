# Java Programs

A collection of Java practice programs written while learning core Java concepts.

## Contents
| `ArrayProgramming` / `ArrayPrograms` | Arrays, searching, sorting, 2D/jagged arrays |
| `Controls` | If-else and conditional logic |
| `SwitchOperation` | Switch-case statements |
| `MethodsPrograms` | Methods, parameters, return values |
| `NumberPrograms` | Number theory — factorial, prime, Armstrong, Fibonacci, GCD, palindrome |
| `NumbersAndStaresPattern` | Number and star pattern printing |
| `Pattern` | Pattern printing exercises |
| `DivisiblityByNumbers` | Divisibility checks |

## About

Written as part of core Java practice — each folder is a separate small project focused on one concept.
